# Handy presentation demo

This branch runs the current Handy UI against a deterministic browser-only adapter. It makes no requests to Claude, Dial, Keewano, Darwin, Alike, or repair providers.

## Presenter flow

1. Open the homeowner demo and choose **Try a sample photo**.
2. The sample leak description is filled in; select **Send to Handy**.
3. Handy shows its preliminary assessment and rapidly simulates provider outreach.
4. Compare the three structured quotes and optionally open **What was said**.
5. Choose a provider, pick one or more time windows, check the explicit approval box, then select **Yes, approve and book**.
6. Review the simulated confirmation. Use **Reset demo** in the lower-right corner before another run.

The interface labels calls, prices, and bookings as simulated. Dates are generated relative to the day the demo is opened, so offered times do not expire during the presentation.
