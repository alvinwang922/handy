# Engineering designs

- [Dial SMS and call agents](dial-sms-and-calls.md): proposed architecture, app integration, communication workflows, and implementation milestones.

The Dial proposal was written against the original static prototype. The repository has since gained a Next.js backend and shared contracts. Before implementing the proposal, reconcile it with the [current implementation spec](../docs/superpowers/specs/2026-10-11-handled-design.md), [shared types](../lib/types.ts), and [team conventions](../CLAUDE.md). Its proposed endpoints and persistence choices are design recommendations, not a description of the current backend.
